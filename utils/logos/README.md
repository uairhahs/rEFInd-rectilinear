Vector sources for OS logos redrawn into icons by `make_icons.sh`.

- `cachyos.svg`: the official CachyOS logo, from
  https://github.com/CachyOS/CachyOS-Settings (`usr/share/icons/cachyos.svg`).
  The logo is CachyOS's artwork, not part of this theme's licence.
- `steamos.svg`: the current SteamOS mark, rebuilt as vector from measurements of
  a reference icon (SteamGridDB). It is a reconstruction, not an official file, and
  the ring is light so it reads on dark backgrounds. SteamOS and its logo belong to
  Valve; the Commons "SteamOS logo.svg" is the old wordmark and is not used.
